# Reels

Reels is a Julia-native LoRA trainer for video diffusion transformers. It
provides checkpoint loading, native text and video preprocessing, mixed
precision training, activation checkpointing, exact resume, compatible adapter
export, distributed data parallelism, and low-VRAM execution for supported Wan
2.1 and LTX-2.3 configurations.

Start with [Installation](installation.md), then select and validate a
[configuration](configuration.md). Model-specific training and compatibility
evidence are organized in the navigation sidebar.

Reels does not distribute model weights. Review [Licensing](licensing.md)
before packaging or redistributing an LTX-enabled build.
